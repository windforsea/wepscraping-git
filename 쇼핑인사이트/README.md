# 네이버 쇼핑인사이트 인기검색어 TOP 10 고객군별 클릭 분석 모듈

NAVER API HUB 쇼핑인사이트 API를 활용하여, 쇼핑 분야별 실시간 인기 검색어 TOP 10을 추출하고 **최근 2일간의 연령, 성별, 기기(PC/모바일)** 고객군별 클릭 데이터를 단일 파일로 통합 수집/분석하는 모듈입니다.

---

## 📌 주요 기능
1. **쇼핑 카테고리별 실시간 인기 검색어 TOP 10 자동 추출**
2. **TOP 10 전체 검색어에 대한 다차원 클릭 트렌드(2일치) 수집**:
   - **기기별**: PC vs 모바일 이용 비중 추이
   - **성별**: 여성 vs 남성 클릭 비중 추이
   - **연령대별**: 10대 ~ 60대 이상 세대별 비중 추이
3. **단일 파일 통합 CSV 저장**:
   - TOP 10개 키워드의 2일치 기기/성별/연령 데이터를 파일 하나에 모두 모아 저장
   - 한글 깨짐 방지(`utf-8-sig`) 적용
   - 저장 파일명: `data/shopping_insight_{카테고리ID}_TOP10_고객군분석_2일치.csv`

---

## 🚀 실행 방법

```bash
# 기본 실행: 패션의류(50000000) 인기검색어 TOP 10 2일치 수집
uv run python 쇼핑인사이트/shopping_insight_analyzer.py

# 카테고리 ID 및 수집 개수 지정 실행
# 사용법: python 쇼핑인사이트/shopping_insight_analyzer.py [카테고리ID] [수집개수]
# 예시: 화장품/미용(50000002) 인기검색어 TOP 10 수집
uv run python 쇼핑인사이트/shopping_insight_analyzer.py "50000002" 10
```

---

## 📑 주요 카테고리 ID (cat_id)
- `50000000`: 패션의류
- `50000001`: 패션잡화
- `50000002`: 화장품/미용
- `50000003`: 디지털/가전
- `50000004`: 가구/인테리어
- `50000005`: 출산/육아
- `50000006`: 식품
- `50000007`: 스포츠/레저
- `50000008`: 생활/건강
