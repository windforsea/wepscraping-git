# 네이버 쇼핑 전체 대표 인기물품 TOP 10 고객군별 클릭 분석 모듈

단일 카테고리에 국한하지 않고, **네이버 쇼핑 전체 주요 10개 분야(의류, 잡화, 뷰티, 가전, 가구, 육아, 식품, 레저, 생활, IT)**를 아우르는 대표 인기 물품 TOP 10을 선별하여, **최근 2일간의 기기(PC/모바일), 성별(남/여), 연령대별(10대~60대)** 고객군 클릭 데이터를 단일 파일로 통합 수집/분석하는 모듈입니다.

---

## 📌 주요 기능
1. **네이버 쇼핑 전체 10개 대표 분야별 실시간 1위 인기 물품 자동 선별**:
   - 패션의류, 패션잡화, 화장품/미용, 디지털/가전, 가구/인테리어, 출산/육아, 식품, 스포츠/레저, 생활/건강, 디지털/IT
2. **TOP 10 물품에 대한 다차원 클릭 트렌드(2일치) 수집**:
   - **기기별**: PC vs 모바일 이용 비중
   - **성별**: 여성 vs 남성 클릭 비중
   - **연령대별**: 10대, 20대, 30대, 40대, 50대, 60대 이상 세대별 비중
3. **단일 파일 통합 CSV 저장**:
   - 10개 대표 물품 전체의 고객군별 2일치 데이터를 단 하나의 CSV 파일에 모아 저장
   - 한글 깨짐 방지(`utf-8-sig`) 적용
   - 저장 파일명: `data/shopping_insight_전체쇼핑_TOP10물품_고객군분석_2일치.csv`

---

## 🚀 실행 방법

```bash
# 네이버 쇼핑 전체 10개 대표 분야 인기 물품 TOP 10 수집 및 분석 실행
uv run python 쇼핑인사이트/shopping_insight_analyzer.py
```
