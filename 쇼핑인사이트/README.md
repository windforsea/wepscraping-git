# 네이버 쇼핑인사이트 고객군별 클릭 데이터 분석 모듈

NAVER API HUB 쇼핑인사이트 API를 활용하여, 쇼핑 인기 검색어를 파악하고 **연령, 성별, 기기(PC/모바일)** 기준으로 클릭 데이터를 나누어 주요 관심 고객층과 이용 패턴을 분석하는 모듈입니다.

---

## 📌 주요 기능
1. **쇼핑 카테고리별 실시간 인기 검색어 TOP 10 조회**
2. **고객군별 다차원 클릭 트렌드 수집 및 분석**:
   - **기기별**: PC vs 모바일 이용 비중
   - **성별**: 여성 vs 남성 클릭 비중
   - **연령대별**: 10대, 20대, 30대, 40대, 50대, 60대 이상 세대별 비중
3. **분석 결과 CSV 저장**:
   - 한글 깨짐 방지(`utf-8-sig`) 적용
   - 저장 위치: `data/shopping_insight_{카테고리ID}_{검색어}_고객군분석.csv`

---

## 🚀 실행 방법

### 방법 1: 기본 실행 (오늘의 인기검색어 1위 자동 분석)
```bash
uv run python 쇼핑인사이트/shopping_insight_analyzer.py
```

### 방법 2: 원하는 키워드, 카테고리, 기간 지정 실행
```bash
# 사용법: python 쇼핑인사이트/shopping_insight_analyzer.py [검색어] [카테고리ID] [분석기간(일)]
# 예시: '원피스' 키워드로 패션의류(50000000) 최근 30일 분석
uv run python 쇼핑인사이트/shopping_insight_analyzer.py "원피스" "50000000" 30
```

---

## 📑 주요 카테고리 ID (cat_id)
- `50000000`: 패션의류
- `50000001`: 패션잡화
- `50000002`: 화장품/미용
- `50000003`: 디지털/가전
- `50000004`: 가구/인테리어
- `50000005`: 출산/육아
- `50000006`: 식품
- `50000007`: 스포츠/레저
- `50000008`: 생활/건강
