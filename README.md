# 네이버 검색어 & 쇼핑 트렌드 수집 프로그램 (GitHub 협업 프로젝트)

네이버 데이터랩(DataLab) 오픈 API를 활용하여 **통합 검색어 트렌드(도서 부문)**와 **네이버 쇼핑 전체 대표 인기물품 고객군별 클릭 트렌드**를 수집하고, 분석 가능한 시계열 데이터(CSV) 및 주피터 노트북(.ipynb)으로 탐색하는 2인 팀 협업 프로젝트입니다.

## 📌 주요 기능

### 1. [검색어트랜드] 도서 인기 검색어 트렌드 수집 및 분석
- 네이버 데이터랩 도서 부문 10개 인기 키워드(`안녕피터팬`, `베스트셀러`, `수족관책`, `원소원정대` 등) 수집
- API의 1회 최대 요청 한도(5개 그룹)를 고려한 자동 분할(Chunking) 및 결합 처리
- 지정 기간(일간/주간/월간) 동안의 검색량 추이를 비교 분석 가능한 CSV 및 노트북 제공

### 2. [쇼핑인사이트] 네이버 쇼핑 전체 대표 인기물품 고객군별 분석
- 단일 카테고리에 갇히지 않고, 쇼핑 전체 10개 대표 분야(의류, 잡화, 뷰티, 가전, 가구, 육아, 식품, 레저, 생활, IT)의 실시간 1위 물품 TOP 10 자동 추출
- 10개 물품에 대해 최근 2일치 기기(PC/모바일), 성별(남/여), 연령대별(10대~60대) 클릭 데이터를 단일 파일로 수집
- 물품별 주 소비 타깃층(예: 여성 97% 의류 vs 남성 69% 노트북 등) 비교 분석

### 3. [공통/선행] 네이버 뉴스 수집기
- 검색어와 수집 건수를 간편하게 수정하여 기사 검색 및 상세 본문(#dic_area) 정적 크롤링(BeautifulSoup) 지원

## 🛠️ 기술 스택
- **Language**: Python 3.14+
- **Package Manager**: `uv`
- **Libraries**:
  - `requests`: 네이버 API 허브(NCP) 및 오픈 API 통신
  - `beautifulsoup4`: HTML 파싱 및 웹 크롤링
  - `pandas`: 트렌드 데이터 정제, 피벗 테이블 집계 및 CSV 변환
  - `ipykernel`: 주피터 인터랙티브 데이터 탐색 환경 지원
  - `python-dotenv`: API 인증키 환경변수 격리 및 로드

## 🚀 시작하기

### 1. 환경 변수 설정
프로젝트 루트 디렉터리에 `.env` 파일을 생성하고 네이버 클라우드 플랫폼(NCP) 또는 개발자 센터 인증키를 등록합니다.
```env
NAVER_CLIENT_ID=여러분의_클라이언트_ID
NAVER_CLIENT_SECRET=여러분의_시크릿_키
```

### 2. 의존성 패키지 동기화
```bash
uv sync
```
